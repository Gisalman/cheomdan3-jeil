# 제일풍경채 첨단3지구 A6BL — 분양 안내 페이지

광주 첨단3지구 A6BL 「제일풍경채」 분양 홍보용 반응형 단일 페이지입니다.
PC·모바일이 같은 파일 하나(`index.html`)로 동작하며, 이미지는 모두 `./images/` 상대경로입니다.

```
cheomdan3-jeil/
├── index.html                 # 페이지 본체 (CSS·JS 인라인, 외부 요청 없음)
├── images/                    # 브리핑북·교육자료 PDF에서 추출한 실제 이미지 13종
├── preview-pc-fold.png        # PC(1440×900) 첫 화면
├── preview-mobile-fold.png    # 모바일(390×844) 첫 화면
├── README.md
├── tools/extract-images.py    # PDF → images 재추출 스크립트
└── tests/site-check.py        # 렌더링·탭·폼 E2E 검증 (Playwright)
```

## 1. 보는 방법

```bash
# 로컬 서버 (방문예약 폼 접수까지 실제로 동작)
cd <workspace>
python3 -m http.server 8080
# → http://localhost:8080/cheomdan3-jeil/index.html
```

`index.html`을 더블클릭해 `file://`로 열면 화면은 모두 보이지만,
브라우저 보안 정책상 폼 전송이 막혀 **"웹 주소(HTTP/HTTPS)로 게시한 뒤 이용해 주세요"** 안내 모달이 뜹니다.
실제 접수는 호스팅(HTTP/HTTPS)에 올린 뒤에 동작합니다.
